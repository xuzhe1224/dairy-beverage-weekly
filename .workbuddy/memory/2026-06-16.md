### 技术要点（避免再踩坑）
- 隔离 Python 环境的二进制签名有问题（`Pillow`/`lxml`/`fontTools`等报 not installed）
- `weasyprint` 在 macOS 沙箱 Python 下安装失败（dylib签名问题）
- 可靠的方案：
  1. PDF：系统 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` 无头模式 `--print-to-pdf`
  2. PPT：`/usr/bin/python3` 装 `python-pptx` + `matplotlib`，`MPLCONFIGDIR=/tmp/matplotlib_cache` 环境变量
  3. matplotlib 颜色参数必须用十六进制字符串（如 `'#222222'`），不能用 `RGBColor`
  4. pptx 3.9 兼容：`add_textbox` 内部 `from pptx.util import Inches, Pt` 要齐全
- CloudStudio 沙箱部署：调用 `workbuddy_cloudstudio_deploy`，传 `directory` 即可
